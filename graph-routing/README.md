# graph-routing

Routing and pathfinding experiments with different levels of polish.

## Files

- `weighted-grid-travel-time.py` - computes the fastest route across a grid with terrain-dependent movement costs.
- `grid-adjacency-draft.py` - a rough draft for building adjacency lists from a grid.
- `grid-dijkstra-demo.py` - a stripped-down shortest-path prototype.
- `air-route-a-star.py` - an A* planner for air routes with fuel and refuel logic.

## Theme

This folder is the "routes and movement" branch of the repo: grids, graphs, and optimized paths.
