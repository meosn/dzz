# data-structures

Linked lists, undo stacks, and balanced trees.

## Files

- `singly-linked-list.py` - a custom singly linked list with insert, remove, and merge utilities.
- `doubly-linked-list.py` - a doubly linked list implementation with optional cyclic mode.
- `undo-redo-history.py` - a history timeline that supports undo/redo behavior.
- `treap.py` - a treap implementation with rotations and deletion.

## Theme

This folder collects the "classic data structure" experiments from the repo.
